# GNSS-LiDAR-Localization
Localization based on GNSS and LiDAR measurements fusion, to achieve a high frequent pose estimate.

## Methodology
We set up an automated driving localization stack in ROS2, using KISS-ICP initially for LIDAR Odometry and extending the problem by incorporating low-frequency GNSS measurements for improved pose estimation
